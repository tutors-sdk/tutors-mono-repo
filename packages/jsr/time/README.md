# Tutors Time Library

Time-related utilities and types for the Tutors learning platform.

## Features

- Time utilities: Functions for time manipulation and formatting
- Date handling: Tools for date calculations and conversions
- Scheduling: Support for time-based scheduling and calendar operations

## Key Components

- `types/`: Type definitions for time-related data structures
- `services/`: Core services for time management
- `utils/`: Utility functions for time calculations and formatting

## Usage

This module provides types, classes and functions for use by other applications
